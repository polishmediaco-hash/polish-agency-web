# Zero-Fluff & Anti-Filler Rule

Strict zero-tolerance policy against AI fluff, theatrical jargon, flowery adjectives, and filler text.

## 1. Core Mandate
Write like a senior operator, technical engineer, or direct agency director. Never write like an AI poet or marketing copy generator. Speak plainly, directly, and tersely.

## 2. Strictly Banned Vocabulary & Tropes
Never output or generate UI copy containing:
- "Living canvas", "living obsidian canvas", "caustic breathing", "ambient caustics"
- "Sensual", "haute couture", "haute parfumerie", "parisian cosmetic laboratory"
- "Emotional apex", "hallmark of luxury", "radiant hallmark", "velvet luminescence"
- "Whispers of elegance", "alchemy", "secret sanctum", "executive atelier"
- "Delve into", "tapestry", "beacon", "testament to", "nestled in"
- "Unlock the power of", "in today's fast-paced digital landscape", "game-changer"
- Pretentious scoring or self-praise ("9.9/10", "Masterpiece", "Flawless")

## 3. UI Copy Standard
Use clean, concise, industry-standard terms:
- Use "Sign In" instead of "Secure Executive Gateway"
- Use "Company Info" instead of "Commercial DNA"
- Use "Application Details" instead of "Intake Growth Diagnostic"
- Use "Video Player" instead of "Private Cinema Theatre"
- Use "Notes" instead of "Executive Calibration Notes"
- Use "Leads" instead of "Inbound Dossiers"

## 4. Output Structure
- State the problem or action directly.
- Show the exact code, file, or command.
- No throat-clearing intros ("Certainly! I'd be glad to help...").
- No preachy recap conclusions.
